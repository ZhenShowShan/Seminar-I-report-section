# System-level Diagnosis - An Introduction and Recent Results 網路診斷
講者: Montclair state University 王大進教授
日期: 0915
筆記:
* 背景動機
    - 硬體趨勢：大規模、高速的多處理器系統與多電腦系統被廣泛部署與應用。
    - 互連網路架構：這些系統依賴各種類型的網路拓撲來連接處理器/計算節點。
    - 系統脆弱性劇增：
        - 系統規模（節點數）不斷擴大。
        - 網路惡意攻擊日益猖獗。
        - 結論：在大規模環境下，節點發生故障/失效是不可避免的。
* 常用網路拓撲範例
    * 超立方體
    * 星狀圖
    * k^n立方體
    * 氣泡排序圖
* 一般來說在整個系統當中假設少數量的處理器或是裝置我們能夠維修或是檢查得出來，可靠度可以提升許多，但是變成大量的處理器或是大量的裝置出現的時候，難免會有裝置壞掉的問題，所以才要本論文所提出的自我診斷與多重故障容錯能力
* method:
    - System-Level
        - 定義: 讓系統中的單元彼此互相檢查/測試，並且識別出所有失效的節點
        - example: 鄰居測試模型
            - 如果測得正常可以設為0
            - 如果測得不正常可以設為1
        - 難點在於如果本身測試者正常，結果正常，但是測試者不正常，測試結果會是任意的數據
* 所以本次演講有提出高效的多項式時間診斷演算法，能在大規模節點中快速定位並隔離失效節點，避免錯誤擴散。
