### 代理人（Agent）

- 目的：使機器人具有「自我學習」的功能。
- 運作流程：
  - 機器人從環境取得資訊，轉成「狀態」交給代理人。
  - 代理人進行分析、學習、決策，輸出「決策」。
  - 機器人依決策對環境採取「行動」，環境再回饋新的資訊。

```
        狀態                 資訊
代理人 <------ 機器人 <------------ 環境
(分析/學習/決策) ------> 機器人 ------------> 環境
        決策                 行動
```

## 2. 強化學習（Reinforcement Learning, RL）

### 基本元素

- 代理人（Agent）：與環境互動，以 trial-and-error 的訓練方式學得策略。
- 狀態（State）：將環境資訊轉換成狀態。
- 行動（Action）：代理人能採取的行動，會產生狀態移轉。
- 報酬（Reward）：用來評估動作的好壞。

互動迴圈：Agent 執行 Action -> Environment 回傳 State 與 Reward -> Agent 更新策略。

### Q-Learning 演算法

- 強化學習的一種方法。
- 學習架構：world 產生 State 與 Reinforcement（Reward），經由 Evaluation 與 Update 更新 Policy，再由 Policy 決定 Action 作用於 world。

範例（格子世界，S 為起點、G 為終點、深色為牆）之報酬訊號設計：

| 事件 | 報酬 |
| --- | --- |
| 撞牆 | -100 |
| 到達終點 | +100 |
| 其它 | 0 |

Q 值更新公式：

$$
Q(s,a) \leftarrow Q(s,a) + \beta \left( r + \gamma \max_{a'} Q(s',a') - Q(s,a) \right)
$$

- $\beta$：學習率
- $\gamma$：折扣因子
- $r$：即時報酬
- $s'$：下一個狀態，$a'$：下一個狀態可選的動作

### 深度強化學習（DRL）：Deep Q-Network

從「表格」走向「神經網路」。當狀態空間很大（例如影像、感測資料）時，Q 表無法存放，改用神經網路近似 Q 函數。

| 階段 | 內容 |
| --- | --- |
| 狀態特徵 | 輸入影像 / 感測狀態 $s_t$ |
| 函數近似 | 深度 Q 網路 |
| 行動選擇 | 輸出 $Q(s_t, \text{上/下/左/右})$，即各動作的價值估計 |

## 3. 群體協作

### 資訊如何在群體機器人之間流動？

完全通訊型（FULL）：

- 做法：機器人 1 到 N 之間交換廣泛的狀態與動作。
  - 聯合狀態 $\vec{s} = (s_t^1, s_t^2, \dots, s_t^N)$
  - 聯合動作 $\vec{a} = (a_t^1, a_t^2, \dots, a_t^N)$
  - 聯合報酬 $\vec{r} = (r_{t+1}^1, r_{t+1}^2, \dots, r_{t+1}^N)$
- 優點：資訊最完整。
- 限制：聯合空間與傳輸成本較高。

## 4. 無通訊下的深度合作學習

### 整體概念

將個體行動價值與合作傾向融合，形成更符合群體需求的決策。每個 Agent 各自擁有以下架構，不需要彼此通訊。

深度 Q 網路整合的深度合作模型：

- 深度 Q 網路（DQN）：負責進行決策。
- 深度合作模型（DCM, Deep Cooperative Model）：模仿其它代理人意圖。

```
              +--> DQN : Q_i(s_i, a_i) --+
局部狀態 s_i --+                          +--> ADF（價值融合）--> 行動
              +--> DCM : C_i(s_i, a_i) --+
```

- ADF：將 Q 值與 C 值做價值融合後選出最終動作。

### (1) 深度 Q 網路

架構重點：

- Experience Buffer $D_i$：儲存經驗 $(s_t^i, a_t^i, s_{t+1}^i, r_{t+1}^i, \psi_{t+1}^i, \kappa_{t+1}^i)$。
- Uniform Sampling：從經驗池均勻抽樣 $(s_j, a_j, s_j', r_j, \psi_j, \kappa_j)$ 進行訓練。
- Online Q-network：訓練中的網路，輸出 Q-value。
- Target Q-network：由 Online Q-network 週期性更新（Periodic update），提供穩定的學習目標。
- Action Selection：結合 Q-value 與來自 DCM 的 C-value，決定動作 $a_t^i$ 並作用於環境。
- 環境回傳 Reward $r_{t+1}^i$ 與 Next State $s_{t+1}^i$，再存回經驗池（Storing experiences）。

### (2) 深度合作模型（DCM）

- 建構一個合作策略函數：

$$
C_i(s_i, a_i): \mathbf{S}_i \times \mathbf{A}_i \rightarrow [0, 1] \in \mathbb{R}
$$

- 估計代理人 $i$ 在狀態 $s_i$ 執行動作 $a_i$ 的「合作傾向值」。
- 同樣由 Experience Buffer $D_i$ 經 Uniform Sampling 取得 $s_j$，輸入網路後輸出 $C^i(s_j, a_j; \theta_C^i)$。

| 項目 | 說明 |
| --- | --- |
| 輸入：狀態 - 動作 | 結合局部感測、候選動作與訓練經驗 |
| 輸出：合作傾向 C 值 | 為不同候選動作提供合作適切性的評估 |

### (3) DCM 如何從成功與停滯調整合作值？

| 情況 | 更新規則 | 效果 |
| --- | --- | --- |
| 發生合作停滯或失敗 | $C_{t+1} = C_t - \rho_l C_t$ | 降低該狀態-行動對的合作評分 |
| 沒有發生停滯或合作失敗 | $C_{t+1} = C_t + \rho_w (1 - C_t)$ | 提高該狀態-行動對的合作評分 |

- $\rho_l$、$\rho_w$：分別為失敗時的下降率與成功時的上升率。
- 由公式可知 C 值會被限制在 $[0, 1]$ 之間：失敗時按比例遞減，成功時朝 1 逼近。
- 範例：三個 Agent 共同推動物件（Object）前往 Goal，途中有 Obstacle。每個 Agent 對四個動作 $a_1$ 到 $a_4$（Front / Rear / Left / Right）各有一個合作值，當某動作造成停滯時，該動作的 C 值下降（例如 0.82 降到 0.62），成功時則上升（例如 0.48 升到 0.72）。

---


1. 強化學習讓單一機器人透過 trial-and-error 自我學習；Q-Learning 用表格記錄 Q 值，DQN 用神經網路近似 Q 函數以處理大型狀態空間。
2. 多機器人系統的挑戰：
   - 完全通訊雖資訊完整，但聯合空間大、傳輸成本高。
   - 其他機器人同時在學習，造成非平穩性，使群體決策震盪。
   - 只追求個體最優動作，會造成環境型或非環境型的合作停滯。
3. 解法（無通訊下的深度合作學習）：
   - 每個機器人以 DQN 估計個體 Q 值，以 DCM 估計合作傾向 C 值。
   - 透過 ADF 融合 Q 值與 C 值來選擇動作。
   - DCM 依據合作成功或停滯，以 $\rho_w$、$\rho_l$ 調整 C 值，讓機器人在不通訊的情況下學會「估計合作」。
