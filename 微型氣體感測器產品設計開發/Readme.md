## 1. 研發背景與市場需求

### 1.1 產業趨勢與發展演進
- **MEMS 感測器 20 年演進**：從早期的慣性感測器（加速度計、陀螺儀）、車輛感測器，逐步發展至環境感測（壓力、麥克風、溫濕度、氣體感測器）。
- **車用感測生態系**：全球智慧車輛感測器市場從 2017 年的 $10B 成長至 2023 年的 **$20.4B**（年複合成長率 CAGR +12.7%）。
- **全球氣體感測器市場**：2022 年市場規模約 9.8 億美元，預計 2031 年將成長至 **17.4 億美元**（CAGR 6.6%）。

```
Material (材料開發) ➔ Device (元件製造) ➔ Circuit (電路驗證) ➔ System (系統整合) ➔ Software (演算法軟體) ➔ Application (智慧產品應用)
```

### 1.2 核心應用領域
1. **居家安全與人體健康**：預防一氧化碳 (CO) 中毒、病態建築症候群 (Sick Building Syndrome)、空氣品質相關疾病（呼吸道過敏、心血管疾病、癌症）。
2. **以人為中心之環境偵測**：配合智慧穿戴與手持裝置，與現有建築固定式環境感測器形成立體互補。
3. **智慧工廠與重大工安防護**：半導體廠區、石化工業之易燃與有毒氣體（如氯氣、氫氣、氨氣、硫化氫、有機過氧化物）快速洩漏預警。

## 2. 現有市場痛點與技術價值主張

### 2.1 市售感測器三大痛點
| 痛點維度 | 市售傳統氣體感測器 (如 MQ 系列、TGS 系列) | 造成的系統瓶頸 |
| :--- | :--- | :--- |
| **高能耗** | 功耗高達 **280 mW ~ 850 mW** | 無法長時間應用於可攜式/穿戴式與自供電 IoT 設備 |
| **加熱不均勻** | 採用傳統 2D 平面環繞式加熱，溫度梯度過大 | 感測器穩定性差、基線漂移嚴重、元件壽命偏短 |
| **靈敏度低 / 響應慢** | 反應時間長（通常 >60 秒），低濃度偵測極限不佳 | 氣體外洩時無法在達到爆炸下限前即時預警 |

### 2.2 本團隊的核心價值主張（蕭育仁教授團隊）
-  **超微型化與低功耗**：晶片面積僅 **$0.43\text{ mm}^2$**（尺寸為市售的 $0.02$ 倍），操作功耗僅約 **$11\text{ mW}$**（約為市售傳統陶瓷式的 $0.013$ 倍）。

-  **3D 懸臂底部加熱微結構**：採用背向蝕刻空腔與微熱板懸空絕熱設計，大幅降低基底熱傳導損耗，提升熱場均勻性與耐久性。

## 3. MEMS 氣體感測器設計架構

金屬氧化物半導體 (MOS) 氣體感測器之原理為：**感測薄膜在特定工作溫度下，待測氣體於薄膜表面的吸附與氧化還原反應將改變半導體的導電率，其電阻變化率與待測氣體成分及濃度高度相關，藉此換算氣體濃度。**

```
                  ┌────────────────────────────────────────┐
                  │      Sensing Film (氣體感測膜)          │
                  ├────────────────────────────────────────┤
                  │     Pt sensing lead (白金感測電極)      │
                  ├────────────────────────────────────────┤
                  │     SiO2 protective layer (保護層)     │
                  ├────────────────────────────────────────┤
                  │   Pt heater (白金加熱器) / Al lead (鋁線) │
                  ├────────────────────────────────────────┤
                  │  SiO2 / SiNx passivation (鈍化支撐層)   │
  ┌───────────────┴────────────────────────────────────────┴───────────────┐
  │                           Silicon Substrate                            │
  │                     ┌────────────────────────────┐                     │
  │                     │   Back Etch (背向蝕刻空腔)  │                     │
  └─────────────────────┘                            └─────────────────────┘
```

### 3.1 結構分層說明
1. **Sensing film (氣體感測薄膜)**：最上層之功能性薄膜，依據目標氣體沉積對應之奈米材料。
2. **Pt sensing lead (白金感測電極 - IDT)**：叉指狀電極結構，負責量測感測膜之電阻變化訊號。
3. **$\text{SiO}_2$ protective layer (二氧化矽保護層)**：提供感測電極與下方加熱電極之間的電氣絕緣與熱傳導介面。
4. **Pt heater (白金加熱器)**：底部微型加熱元件，提供感測膜工作所需之精準高溫環境。
5. **Al lead (鋁線電極)**：連接微加熱器之供電引線。
6. **$\text{SiO}_2 / \text{SiN}_x$ passivation film (二氧化矽/氮化矽鈍化支撐層)**：高機械強度且耐熱應力之微懸臂膜片。
7. **Back etch (背蝕刻空腔)**：透過晶圓背面微加工掏空矽基底，切斷主要熱傳導路徑，達成超低功耗微熱板。

### 3.2 目標氣體與感測薄膜材料配方對應
- **一氧化碳 ($\text{CO}$)**：$\text{SnO}_2 + \text{Au}$（二氧化錫結合金奈米顆粒修飾）
- **二氧化氮 ($\text{NO}_2$)**：$\text{WO}_3$（氧化鎢）
- **二氧化硫 ($\text{SO}_2$)**：$\text{NiO}$（氧化鎳）
- **臭氧 ($\text{O}_3$)**：$\text{SnO}_2$（二氧化錫）
- **硫化氫 ($\text{H}_2\text{S}$)**：$\text{Ag}$ 摻雜 $\text{ZnO}$（銀摻雜氧化鋅）

## 4. MEMS 氣體感測器製造流程及成果

團隊建立之 MEMS 氣體感測元件完整微加工與封裝流程如下（(A) 至 (H) 八大階段）：

```
(A) 感測與加熱電極製作 ➔ (B) 感測區保護與加熱電極絕緣 ➔ (C) 結合感測薄膜製作 ➔ (D) 晶片垂直深蝕刻(DRIE)
                                                                                  │
(H) PCB 固晶打線量測   ◀─ (G) 雷切後晶片背視圖(懸空腔) ◀─ (F) 晶片雷射切割      ◀─ (E) 6吋 Wafer 製程完成
```

### 4.1 各階段製程解析
- **(A) 感測與加熱電極製作**：於基底沉積並圖形化白金加熱器（Pt heater）及叉指感測電極（IDT）。
- **(B) 感測區保護與加熱電極絕緣處理**：沉積 $\text{SiO}_2$ 絕緣保護層，防止加熱器與感測電極間發生電氣短路。
- **(C) 加熱電極結合感測膜製作**：於感測區精準沉積目標奈米金屬氧化物半導體感測薄膜。
- **(D) 晶片垂直深蝕刻 (DRIE)**：由晶圓背面進行等離子體垂直深蝕刻，掏空基底矽材，形成懸空微薄膜結構（可見 SEM 截面）。
- **(E) 6 吋 Wafer 製程完成**：實現全晶圓級批次量產，具備數千顆感測晶粒。
- **(F) 雷切晶片 (Laser Dicing)**：利用精密雷射切割將 6 吋晶圓切割為獨立微晶粒。
- **(G) 雷切後晶片背視圖**：清晰顯現背向開孔之懸空微熱板空腔結構。
- **(H) 晶片 PCB 固晶打線量測**：將晶粒黏貼於 PCB / 金屬基座上，並進行金線/鋁線超音波打線（Wire Bonding）以完成電氣連接與量測。

## 6. 銀摻雜氧化鋅薄膜 (Ag/ZnO) 感測原理與反應機制

針對硫化氫 ($\text{H}_2\text{S}$) 與揮發性含硫化合物，團隊開發之 $\text{Ag}$ 摻雜 $\text{ZnO}$ 奈米薄膜具備卓越感度，其表面化學反應機制與物理方程式如下：

### 6.1 反應方程式
1. **空氣中表面氧分子吸附與捕獲自由電子（形成氧負離子耗盡層）：**
   $$\text{O}_2\text{(gas)} + 2e^- \longrightarrow 2\text{O}_2^-\text{(ads)} \quad (1)$$
2. **通入 $\text{H}_2\text{S}$ 氣體，與表面化學吸附氧發生氧化還原反應（釋放電子回導帶）：**
   $$2\text{H}_2\text{S} + 3\text{O}_2^- \longrightarrow 2\text{H}_2\text{O} + \text{SO}_2 + 3e^- \quad (2)$$
3. **表面銀與氧化鋅發生硫化反應，生成硫化銀與硫化鋅（破壞高能障，電阻劇降）：**
   $$\text{Ag}_2\text{O} + \text{H}_2\text{S} \longrightarrow \text{Ag}_2\text{S} + 2\text{H}_2\text{O} \quad (3)$$
   $$\text{ZnO} + \text{H}_2\text{S} \longrightarrow \text{ZnS} + 2\text{H}_2\text{O} \quad (4)$$
4. **重新通入氧氣/空氣之高溫氧化脫附與再生反應（恢復初始高阻態）：**
   $$2\text{Ag}_2\text{S} + 3\text{O}_2 \longrightarrow 2\text{Ag}_2\text{O} + 2\text{SO}_2 \quad (5)$$
   $$2\text{ZnS} + 3\text{O}_2 \longrightarrow 2\text{ZnO} + 2\text{SO}_2 \quad (6)$$

### 6.2 敏化增強機制解析
- **化學敏化 (Chemical Sensitization)**：奈米 $\text{Ag}$ 顆粒具備溢流效應（Spillover effect），在薄膜表面充當催化活性位點，顯著降低氧分子離子化與 $\text{H}_2\text{S}$ 分子裂解所需的活化能。
- **電子敏化 (Electronic Sensitization)**：空氣中 $\text{Ag}$ 氧化為 $\text{Ag}_2\text{O}$，與 $\text{ZnO}$ 形成 p-n 異質結並產生寬大的電子耗盡層（呈現超高電阻態）。當接觸 $\text{H}_2\text{S}$ 時，$\text{Ag}_2\text{O}$ 被迅速還原硫化為具金屬導電特性的 $\text{Ag}_2\text{S}$，能障瞬間瓦解，自由電子大量灌入導帶，使得電阻呈現數個數量級的驟降，大幅提升響應靈敏度與低濃度偵測能力。

## 9. 邊緣運算、IoT 與無人巡檢場域實測

### 9.1 特徵萃取與雲端物聯網
- **特徵萃取 (Feature Extraction)**：分析訊號基線 (Baseline)、反應上升斜率 (On Derivative)、飽和積分 (On Integral)、脫附下降斜率 (Off Derivative)，用於神經網路與機器學習氣體分類辨識。
- **多通道模組與雲端資料庫**：
  - 支援 4 顆不同加熱電壓感測器獨立驅動並自動降壓。
  - 後端串接 SQLite 與 Web 即時圖表，支援每秒 $2,000 \sim 3,000$ 筆即時動態數據串流呈現。

### 9.2 無塵室自走巡檢車實測 (SLAM AMR)
